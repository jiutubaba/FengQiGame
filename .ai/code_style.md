# 代码风格与组织

## 基本原则

- 命名直接表达职责，避免 `utils2`、`common-new`、`temp` 等泛名。
- 优先让一个业务流程在相邻代码中完整可读；只有确有复用或边界价值时抽取 helper。
- 保持现有 ESM、React 函数组件、Express Router、Zod 校验和参数化 SQL 风格。
- 不引入与需求无关的抽象、兼容层、回退分支或新依赖。
- 长文件修改使用小补丁，先定位真实调用链，避免覆盖同文件中的其他有效改动。

## 前端

- 页面不得用硬编码样本替代 API 数据；加载、空状态、错误和权限不足必须可区分。
- 关键加载和表单保存失败应在当前业务上下文内持续展示并提供可恢复入口，成功反馈可使用短暂提示；提交期间必须显示进行中状态并阻止重复操作。危险操作统一使用站内确认弹窗说明对象、影响和不可恢复性，模态框必须支持初始焦点、焦点循环、Escape 关闭与关闭后焦点归还。
- 权限菜单与按钮显隐复用服务端返回权限，但不能被视为安全校验。
- 全站视觉保持 Attio 式白色业务面板与雾灰画布、黑色精密文字和单一低饱和蓝色强调；工作台画布与浏览器主题色为 `#f3f4f6`，常规业务区以留白、1px 边界、轻阴影、表格和列表建立层级，避免渐变光晕、重阴影与无意义卡片墙。登录页品牌画布可使用深石墨背景与单一动态主视觉形成对比，但登录表单仍保持暖白基线，动态视觉不得扩散到登录后业务工作区。响应式断点修改必须检查桌面与窄屏。
- 全站界面字体通过 Fontsource 本地托管并统一使用 `Noto Sans SC Variable`；运行时不得依赖在线字体服务。
- 业务正文和控件默认使用 13–14px；常用导航和页面说明优先使用 14px，辅助说明优先使用 12–13px，11px 仅用于编号、技术元数据等弱层级信息；数字指标使用等宽数字，ID、权限名与技术字段使用等宽字体，窄屏主要点击区域不得小于 44px。
- 颜色、字号、间距、7/10/14px 圆角令牌、阴影、焦点环和动效统一复用 `styles.css`；交互控件必须具备键盘焦点状态。行与按钮反馈、抽屉与模态框使用约 140–200ms 的统一节奏，页面进入为 280ms，并为 `prefers-reduced-motion` 提供降级。
- 登录后工作台采用均衡紧凑密度：桌面默认侧栏宽 236px、顶栏高 58px，内容最大宽度 1680px；页面标题约 27px，页面区块间距 18px，工具栏约 50px，桌面控件 36–40px，表格表头约 40px、数据行 46–48px；移动端控件仍不得低于 44px。地图中心卡片网格按宽度使用 4/3/2/1 列，封面控制在约 136–164px，占位封面使用浅灰网格和居中小标记，列表行控制在约 120px。
- 地图工作台顶栏必须明确“地图中心 / 当前地图 / 当前功能”层级，窄屏提供同级功能的横向快速切换；关键搜索、筛选、排序和分页状态优先写入 URL，并在结果区展示当前视图摘要。窄屏横向表格必须给出滑动提示，关键操作列保持可达。
- `MapWorkspace.jsx` 只负责地图工作台壳层、权限门禁和面板装配；业务面板继续收口在 `src/pages/map-workspace/` 对应领域文件，不得重新堆回组合入口。
- 项目数据采用活跃与对局、用户规模、留存与复玩三栏指标概览，下方独立展示所选指标趋势；中屏分组纵排、指标横排，窄屏指标两列。名称、辅助说明和数值统一对齐，整行可选，口径提示独立操作。趋势绘图区固定高 224px，按容器宽度调整横坐标，文字与节点不随宽度缩放；坐标只在数据、指标或容器宽度改变时重新计算，保留缺失样本断线、键盘定位和完整日期提示。项目数据分类导航由工作台壳层统一提供，不通过导入业务面板复用导航。
- 项目配置按项目设置、运营配置、数据与代码分组；基础表单与生命周期操作分区，预加载编辑器仅进入对应板块时加载。结构化编辑区标明配置字段、JSON 格式和编辑状态；保留未保存切换确认、保存失败反馈及服务端权限边界。

## 服务端与数据库

- 所有外部输入先经 Zod 或等价明确校验；SQL 必须参数化。
- 多表原子操作使用 `transaction`；错误使用统一 `HttpError`/错误处理中间件。
- `server/routes/maps.js` 只负责按原顺序组合 `server/routes/maps/` 下的领域路由；领域私有 helper 留在本领域，只有跨领域复用且语义稳定的内容才进入 `shared.js`。
- 新表或字段只通过递增迁移新增；已发布迁移不得原地改写。
- 变更权限、路由、环境变量或迁移后必须刷新自动事实。

## 文档与注释

- 注释解释业务原因、边界或危险点，不复述语句本身。
- 稳定合约写入对应 `systems/` 文档；长期取舍写 ADR；一次性过程只进入会话归档。
- `.ai/generated/` 只能由工具生成。
